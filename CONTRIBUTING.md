# Contributing

Thanks for your interest in contributing to **AISWS-ACA（AI超站）**.

## Getting started

- Read `docs/README.md` (documentation index)
- Dev setup: `docs/engineering/DEVELOPMENT.md`
- Scripts: `docs/engineering/SCRIPTS.md`

## Development workflow

1) Create a feature branch
2) Keep changes focused and minimal
3) Add/update tests for Go changes (`backend/`)
4) Run:
- `cd backend && go test ./...`
- `cd frontend && npm run build` (if frontend changed)
5) Open a PR with:
- problem statement
- solution summary
- screenshots (UI changes)
- testing evidence
