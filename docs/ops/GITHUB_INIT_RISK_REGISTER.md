# github-init 风险台账（门禁迭代）

> 适用范围：`github-init` 分步迭代（S0-S7）  
> 更新规则：每个 Step 结束必须更新状态、影响面、缓解动作与下一步控制项。

## 状态定义

- `open`：风险存在且未落地缓解
- `mitigating`：已实施缓解但未完全验证
- `controlled`：已验证可控，保留观察
- `closed`：风险已关闭
